# 🎮 ربات بازی الدوریا (Eldoria)

یه ربات RPG متنی با دکمه‌های شیشه‌ای (inline keyboard) برای تلگرام.

## امکانات
- ساخت کاراکتر: انتخاب اسم، جنسیت و کلاس (جنگجو / جادوگر / کماندار)
- **پایتخت**: منطقه‌ی امن که هیچ نبردی توش اتفاق نمی‌افته
- ۴ منطقه‌ی خطرناک: شرق، غرب، شمال، جنوب — هرکدوم مأب و باس مخصوص خودشون رو دارن
- سیستم لول و تجربه (XP) با رشد آمار در هر لول‌آپ
- آمار کامل: HP، قدرت حمله، دفاع، طلا
- اینونتوری با آیتم (معجون، سلاح، زره) قابل تجهیز و مصرف
- مبارزه‌ی نوبتی: حمله / دفاع / استفاده از آیتم / فرار
- باس هر منطقه با حداقل لول ورودی و لوت ویژه

## نصب و اجرا

۱. پایتون ۳.۱۰ یا بالاتر لازمه.

۲. نصب پکیج‌ها:
```bash
pip install -r requirements.txt
```

۳. یه ربات تلگرامی از [@BotFather](https://t.me/BotFather) بساز و توکنش رو بگیر.

۴. توکن رو به‌عنوان متغیر محیطی تنظیم کن و ربات رو اجرا کن (نسخه‌ی محلی/polling):
```bash
export BOT_TOKEN="توکن_ربات_تو"
python3 bot_local.py
```

روی ویندوز (PowerShell):
```powershell
$env:BOT_TOKEN="توکن_ربات_تو"
python bot_local.py
```

با اجرای این دستور، ربات شروع به polling می‌کنه. کافیه توی تلگرام بهش پیام `/start` بدی.

## ساختار پروژه
```
eldoria_bot/
├── bot.py            # اجرای وب‌هوک (برای دیپلوی روی Render)
├── bot_local.py       # اجرای polling (برای تست روی سیستم شخصی)
├── database.py        # لایه‌ی دیتابیس SQLite (بازیکن‌ها و اینونتوری)
├── game_data.py        # داده‌های ثابت: کلاس‌ها، آیتم‌ها، مناطق، مأب‌ها، باس‌ها
├── keyboards.py        # کیبوردهای شیشه‌ای (inline)
├── handlers.py         # منطق اصلی بازی (هندلرها)
└── requirements.txt
```
دیتابیس به‌صورت خودکار در فایل `eldoria.db` (SQLite) ساخته می‌شه.

## دیپلوی رایگان روی Render (حالت Webhook)

فایل `bot.py` برای اجرا به‌صورت **وب‌هوک** روی Render (پلن رایگان Web Service) آماده‌ست.

۱. کد رو توی یه ریپازیتوری GitHub قرار بده (public یا private، مهم نیست).

۲. توی [render.com](https://render.com) حساب بساز (میشه با GitHub لاگین کرد) و:
   - **New +** → **Web Service** رو بزن
   - ریپازیتوری‌ت رو انتخاب کن
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Instance Type**: Free

۳. توی بخش **Environment** این متغیر رو اضافه کن:
   - `BOT_TOKEN` = توکنی که از BotFather گرفتی

   (نیازی نیست `PORT` یا `RENDER_EXTERNAL_URL` رو دستی بزنی، Render خودش این‌ها رو ست می‌کنه.)

۴. **Deploy** بزن. وقتی سرویس بالا اومد، بات خودکار وب‌هوکش رو نزد تلگرام ثبت می‌کنه.

۵. برو تو تلگرام و `/start` بزن.

**نکته:** روی پلن رایگان Render، اگه سرویس ۱۵ دقیقه پیام نگیره می‌خوابه. اولین پیام بعد از خواب ممکنه چند ثانیه تا حدود یک دقیقه طول بکشه تا جواب بیاد (چون سرویس باید بیدار بشه) — بعدش عادی و سریع کار می‌کنه.


- سیستم شهر/فروشگاه برای خرید آیتم با طلا در پایتخت
- ماموریت‌های روزانه (daily quest)
- سیستم گروه/کلن یا PvP بین بازیکن‌ها
- محدودیت زمانی (cooldown) برای مبارزه با باس
- افزودن منطقه‌ها یا کلاس‌های بیشتر با ویرایش `game_data.py`

هر بخش رو می‌تونی به سادگی توی `game_data.py` (بدون دست زدن به منطق بازی) گسترش بدی — چون همه‌ی مأب‌ها، آیتم‌ها و مناطق به‌صورت دیکشنری تعریف شدن.
